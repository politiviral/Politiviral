# Politiviral Website v1

A mobile-friendly public-facing Politiviral homepage.

## Files
- `index.html` — homepage
- `styles.css` — responsive design
- `script.js` — content and navigation
- `data/campaigns.json` — starter campaign data

## GitHub Pages
Upload these files to the root of the `main` branch, then set GitHub Pages to deploy from `main` / `/(root)`.
